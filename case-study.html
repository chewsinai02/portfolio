HEALTHCARE FYP · OWNED

Patient Care Real-Time Management

Problem

Hospitals and families needed a single channel for care updates—not scattered phone calls and paper handoffs. Staff required role-based web access; patients needed a mobile-friendly way to stay informed.

My role

Sole developer for final-year project: designed database schema, built Laravel admin portal (doctor, nurse, nurse admin, admin), and Flutter patient app. Integrated Firebase for push and real-time features.

Stack & architecture

Laravel Flutter MySQL Firebase

Split architecture: PHP backend for staff workflows and APIs; Flutter client for patients. Real-time messaging connects care teams and families without exposing internal hospital systems publicly.

Outcome

  • Delivered working web + mobile demo used in FYP presentation and documentation
  • Role-based portals reduce confusion between admin, clinical, and patient surfaces
  • Reusable pattern for event-driven updates applicable to other notification-heavy domains

AI Mail & Document Pipeline (MyCeids)

Problem

Operations teams received bundles of documents via email and manual uploads. Re-keying data into MyCeids was slow, error-prone, and blocked on staff availability.

My role

Built the end-to-end pipeline: PHP email receiver and upload APIs, document conversion and compression, Gemini classification/extraction, Node + Playwright server automation, and Vite + React review UI.

Stack & architecture

Vite React PHP Node Playwright Gemini

Documents enter via email attachments or manual upload (not both required). ZIP and Office files unpack; content converts to PDF, compresses when large, then Gemini extracts fields. Playwright runs headless Chromium to complete MyCeids portal steps. React UI lets users review before hand-off.

Outcome

  • Single pipeline replaces repetitive manual portal entry for structured document batches
  • Dual ingestion paths fit both email-driven and ad-hoc upload workflows
  • Published user manual and public repo demonstrate operability for reviewers
